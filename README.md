# CustomWeapons (Pyromania)

Paper 1.21.4+ plugin. No resource pack needed.

## Pyromania
A netherite sword (same damage, can be enchanted normally).
- F key (swap hands): Ember Dash - 15s cooldown. Dash with a blazing tail; entities you pass through take 2 hearts
  plus 5 seconds of burning that ignores Fire Resistance.
- Shift + F: Fireball - 30s cooldown. A fire charge that explodes for 3 hearts (no block damage)
  plus 5 seconds of burning that ignores Fire Resistance.
- Anywhere in your inventory: permanent Fire Resistance.
- Cooldowns show as a boss bar that drains; when it's empty the ability is ready.

Get it with: /weapon give pyromania [player]   (ops only)

## Get the .jar
1. Create a new GitHub repository and upload everything in this folder (including the hidden .github folder).
2. Actions tab -> wait for "Build CustomWeapons" to turn green.
3. Open the run -> Artifacts -> CustomWeapons -> unzip -> CustomWeapons.jar.
4. Put it in your server's plugins folder and restart.
